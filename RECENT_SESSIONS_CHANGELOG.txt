  ── Concepts clarification ───────────────────────────────────────────────────

  GateMode:
    Quyết định cổng nào (TDPathGroup nào) mỗi wave dùng.
    RoundRobin  → wave 0→gate0, wave 1→gate1, wave 2→gate0, ...
    Random      → random gate mỗi wave
    PerWave     → cả wave gắn 1 gate cố định theo wave index
    Simultaneous→ tất cả gates spawn song song cùng lúc mỗi wave

  Layout:
    Quyết định start/end nằm ở border nào.
    LeftToRight    → S: Left,   E: Right  (classic)
    RightToLeft    → S: Right,  E: Left
    TopToBottom    → S: Top,    E: Bottom
    BottomToTop    → S: Bottom, E: Top
    Diagonal_TL_BR → S: Top,    E: Right
    Diagonal_BL_TR → S: Bottom, E: Right

  Path diversity (PathCount):
    PathCount=1 → 1 đường cố định/group
    PathCount=3 → 3 corridors khác nhau/group, random mỗi wave

  ── TDOperatorSelectionView — camera-aware retreat panel anchor ──────────────

  File: Assets/2.Scripts/View/GamePlay/Tower/TDOperatorSelectionView.cs

  User request: panel always at the upper-left edge midpoint of the diamond
                indicator, centered on that edge.

  Replaced hardcoded worldPos + Vector3.up * offset with GetIndicatorUpperLeftEdge():

  Algorithm:
    1. Compute 4 L1 diamond tips using transform.right / transform.up × halfScale
       (works for any Quad rotation, including Euler(90,0,45))
    2. Project all 4 tips to screen space via Camera.main.WorldToScreenPoint
    3. topIdx  = tip with highest screen Y  (topmost in screen)
    4. leftIdx = tip with lowest screen X   (leftmost in screen)
    5. Return (tips[topIdx] + tips[leftIdx]) × 0.5f — midpoint of upper-left edge

  Fallback to op.transform.position + Vector3.up * OPERATOR_PANEL_WORLD_Y_OFFSET
  when SelectionIndicatorTransform is null.

  Camera-independent: recalculates every frame in Update → correct for any
  camera angle or movement.
