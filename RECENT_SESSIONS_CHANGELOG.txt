  Goal: Thay thế Y-zones zigzag path gen bằng Recursive Backtracker maze extraction

  ── Architecture change: Path Generation ────────────────────────────────────

  TRƯỚC (Y-zones zigzag):
    TDPathGeneratorControl.GenerateRandomWaypoints() → Y-zones
    TDaStarPathControl.BuildDefinedPath() → straight H/V segments
    TDObstacleControl.PlaceObstacles() → random trees/rocks trên valid cells

  SAU (Maze Extraction):
    TDMazePathGenerator.GenerateMultiplePaths(N=3)
      → Gen N mazes độc lập (Recursive Backtracker)
      → A* extract 1 shortest path/maze
      → Combine: union of N path cells = walkable (corridor)
      → Wall cells (!isWalkable) = tower placement spots
    TDEnemyPathMainControl.GenerateAllPaths() → call MazePathGenerator
    TDEnemyPathMainControl.ComputeValidTowerCells() → wall cells only (new logic)
