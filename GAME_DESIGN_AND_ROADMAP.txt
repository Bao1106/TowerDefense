 5. PATH GENERATION ALGORITHM (TDPathGeneratorControl)
════════════════════════════════════════════════════════════════════════════════

  Input  : start (Vector2Int), end (Vector2Int), yMin, yMax (zone bounds)
  Output : Vector2Int[] waypoints, mỗi cặp liên tiếp cùng X HOẶC cùng Y

  Algorithm:
    1. Enter zone: enterY = Random(yMin, yMax)
       if enterY != start.y → add (start.x, enterY)

    2. Zigzag loop:
       while (curX + minStep <= end.x - 1):
         stepX = Random(minStep, maxStep); nextX = min(curX+stepX, end.x-1)
         add (nextX, curY); curX = nextX
         nextY = PickDifferentY(curY, yMin, yMax, minDelta)
         add (curX, nextY); curY = nextY

    3. Exit: if curX != end.x → add (end.x, curY)

  Tunables:
    CONFIG_PATH_MIN_STEP_X         = 2
    CONFIG_PATH_MAX_STEP_X         = 5
    CONFIG_PATH_MIN_VERTICAL_DELTA = 2


════════════════════════════════════════════════════════════════════════════════
 6. BUILD DEFINED PATH ALGORITHM (TDaStarPathControl.BuildDefinedPath)
════════════════════════════════════════════════════════════════════════════════

  Input  : gridDTO, start, end, waypoints[]
  Output : List<IGridCellDTO>

  BuildDefinedPath:
    path=[]; cur=start
    foreach wp in waypoints: AppendStraightSegment(path, cur, wp); cur=wp
    AppendStraightSegment(path, cur, end)
    path.Add(cell(end))

  AppendStraightSegment: move X first, then Y (Manhattan walk, no A*)

 11. ENEMY MOVEMENT (TDEnemyView)
════════════════════════════════════════════════════════════════════════════════

  State fields:
    m_PathsPosition    : List<Vector3>  (world positions của path)
    m_CurrentPathIndex : int
    m_HasReachedEnd    : bool           ← guard tránh LoseLife nhiều lần [4.5]
    m_HasBeenReturned  : bool           ← guard tránh double ReturnToPool [8.5]
    m_EnemyHealth      : float          ← set từ SpawnBatch (baseHP × hpMult) [Phase 11]
    m_MoveSpeed        : float          ← set từ SpawnBatch (baseSpeed × speedMult) [Phase 11]
    m_EnemyKey         : string         ← unique "w{wave}-{type}-e{i}-{instanceId}"
    EnemyType          : EnemyType      ← property { get; private set; } [Phase 11]

  PathProgress: m_CurrentPathIndex / m_PathsPosition.Count (0→1)
    → Tower dùng để ưu tiên enemy gần GateEnd nhất

  Initialize(key, hp, speed, enemyType): reset state, set stats, Subscribe, Register [Phase 11]
  ReturnToPool():  guard m_HasBeenReturned → Unsubscribe → Unregister → Pool.Release [8.5]
  TakeDamage(dmg): health -= dmg; health ≤ 0 → ReturnToPool() [không Destroy]
  OnDestroy():     chỉ cleanup nếu !m_HasBeenReturned (scene unload safety)

  Update():
    guard: m_PathsPosition==null || Count==0 || m_HasReachedEnd → return
    if m_CurrentPathIndex < Count:
      MoveTowards(target, speed*dt)
      LookRotation(dir)
      if dist < 0.1f: m_CurrentPathIndex++
    else:
      m_HasReachedEnd = true
      TDPlayerLifeControl.api.LoseLife()
      ReturnToPool()   ← [Phase 8.5: không Destroy — pool release]

  ── LevelConfig System ────────────────────────────────────────────────────────

  Approach: Difficulty + TotalEnemies → auto-distribute (Hướng B)
  Lý do chọn B:
    - Designer set 2 field là xong (không phải 4 count riêng lẻ)
    - Difficulty ratio đảm bảo balance nhất quán
    - totalEnemies cho phép từng màn có cá tính riêng (dù cùng difficulty)
    - Dễ mở rộng: thêm difficulty level mới chỉ cần thêm 1 dòng config

  Difficulty enum:
    public enum Difficulty { Easy, Normal, Hard, Extreme, Nightmare }

  Difficulty Ratio Table (phân phối % + multiplier stats):

    Difficulty | Normal% | Fast% | Tank% | Boss% | HP mult | Speed mult
    -----------|---------|-------|-------|-------|---------|------------
    Easy       |   80%   |  15%  |   4%  |   1%  |  ×0.8   |   ×0.9
    Normal     |   60%   |  25%  |  12%  |   3%  |  ×1.0   |   ×1.0
    Hard       |   45%   |  30%  |  18%  |   7%  |  ×1.2   |   ×1.1
    Extreme    |   30%   |  30%  |  25%  |  15%  |  ×1.5   |   ×1.2
    Nightmare  |   15%   |  25%  |  35%  |  25%  |  ×2.0   |   ×1.5

  Ví dụ: difficulty=Hard, totalEnemies=50
    Normal = 45% × 50 = 22.5 → 23 con
    Fast   = 30% × 50 = 15   → 15 con
    Tank   = 18% × 50 =  9   →  9 con
    Boss   =  7% × 50 =  3.5 →  3 con
    (làm tròn, đảm bảo sum = totalEnemies)

  HP/Speed multiplier apply lúc runtime khi spawn:
    float hp    = baseData.baseHP    * difficultyConfig.hpMult;
    float speed = baseData.baseSpeed * difficultyConfig.speedMult;

  ── 2-Path System ─────────────────────────────────────────────────────────────

  Mỗi màn có 2 đường → enemy split theo path1Ratio:
    path1Count = Round(totalEnemies × path1Ratio)
    path2Count = totalEnemies - path1Count

  Phân phối type ratio tính trước → sau đó split:
    path1: tỉ lệ type tương đương, Boss ưu tiên path nhiều hơn (path1 nếu path1Ratio ≥ 0.5)

  Spawn: mỗi path có spawn queue riêng, spawn đan xen (hoặc đồng thời)

  ── Wave Subdivision Auto ─────────────────────────────────────────────────────

  totalEnemies chia đều cho waveCount:
    basePerWave = totalEnemies / waveCount
    remainder   = totalEnemies % waveCount (distributed to first N waves)

  Mỗi wave: spawn basePerWave (hoặc +1) enemy, cách nhau spawnInterval giây
  Giữa các wave: waveInterval giây (qua PauseAwareDelay)

  ── Spawn Logic Flow (Phase 11) ───────────────────────────────────────────────

  1. LevelConfig loaded từ SO → GetLevel(levelIndex)
  2. Auto-distribute: DifficultyRatioTable → counts per type (Normal/Fast/Tank/Boss)
  3. Split thành 2 spawn queues (path1 / path2) theo path1Ratio
  4. Chia đều theo waveCount → spawnQueuePerWave[][]
  5. For each wave:
       onWaveStart → GateView.PlaySpawnEffect()
       For each enemy in wave:
         Xác định EnemyType từ queue → lấy EnemyData → tính HP×mult, speed×mult
         GetOrSpawn prefab tương ứng từ pool
         enemy.Initialize(key, hp, speed)
         await PauseAwareDelay(spawnInterval)
       await PauseAwareDelay(waveInterval)
