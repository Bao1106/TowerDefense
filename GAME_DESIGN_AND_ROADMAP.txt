  Grid height = Floor(30 / 2f) = 15           (TDGridMainModel.cs runtime)       [updated s29]
  Total cells = 300                                                               [updated s29]

  Offset calculation (TDGridMainModel.cs):
    offsetX = planePos.x - (mapSize.x/2) + (cellSize/2) = 24.5 - 20 + 1 = 5.5  [updated s29]
    offsetZ = planePos.z - (mapSize.z/2) + (cellSize/2) = 23   - 15 + 1 = 9.0  [updated s29]

  Cell (x,y) → world = (x*2 + 5.5,  0,  y*2 + 9.0)
    Cell (0,  0)  → world (5.5,  0, 9.0)    ← bottom-left
    Cell (19, 14) → world (43.5, 0, 37.0)   ← top-right
    Cell (0,  6)  → world (5.5,  0, 21.0)   ← default START gate (centerY=6, even snap)
    Cell (18, 6)  → world (41.5, 0, 21.0)   ← default END gate   (lastCol=18, even snap)

  Start/End dynamic calculation (s29):
    centerY = height/2 (integer) = 7; if odd → centerY-- → 6

 5. PATH GENERATION ALGORITHM [CURRENT — Maze Extraction, s29+]
════════════════════════════════════════════════════════════════════════════════

  ⚠️  THAY THẾ: Y-zones zigzag (TDPathGeneratorControl) và BuildDefinedPath bị xóa s29.
  ⚠️  TDPathGeneratorControl.cs: DELETED s29. TDObstacleControl.cs: DELETED s29.

  ALGORITHM: Recursive Backtracker Maze Extraction (TDMazePathGenerator.cs)

  GenerateForGroups(gridDTO, groups):
    foreach group in groups:
      PathCount = CONFIG_NUM_PATHS  (3 corridors/group)
      foreach run in 0..PathCount:
        Carve(gridDTO, group, allGroups) → 1 corridor
        combinedPathCells |= corridor.cells
    SetAllWalls() 1 lần cuối → restore isWalkable trên combined

  Carve(gridDTO, group, allGroups):
    1. SetAllWalls() — đặt tất cả ô isWalkable=false
    2. Block gate cells của groups KHÁC (ngăn A* shortcut qua cổng sai)
    3. CarveFrom(startCell): iterative Stack<Vector2Int>
       Room cells tại even (x,y) coords; passage cells giữa 2 room
       Shuffle 4 hướng random → carve đến room chưa thăm
    4. A* extract path từ group.StartCell → group.EndCell
    5. minLength = gridWidth; retry ≤ 10 lần nếu path.Count < minLength
       Fallback: giữ path dài nhất tìm được
    6. Unblock gate cells đã bị block ở bước 2

  Wall cells  (!isWalkable after GenerateForGroups) = tower placement spots
  Corridor    (isWalkable after GenerateForGroups)  = enemy path

  Key constants:
    CONFIG_NUM_PATHS                = 3   (corridors per group)
    CONFIG_MAZE_OBSTACLE_WALL_RATIO = 0.15f (15% wall cells → obstacle decoration)
    CONFIG_MAZE_EXTRA_PASSAGE_RATE  = 0.45f (reserved, not yet used)

 8. GATE START / GATE END (Phase 4.5 + 4.6 — DONE)
════════════════════════════════════════════════════════════════════════════════

  ── Visual Design (Phase 4.6 — Session 6) ────────────────────────────────────

  Arknights-style 3D wireframe box visible from 30° orthographic camera.
  Box dimensions: 2×2u footprint, 2.2u tall, raised +0.13u above ground
  (path tiles sit at y=0.1 → box bottom ring at y=0.13+0.035=0.165 → clears tiles)

  Box structure (12 edges + 5 face fills):
    4 corner posts  : Post_FL / Post_FR / Post_BL / Post_BR
                      size 0.07×2.20×0.07u, placed at (±hs, hh, ±hs)
    4 bottom ring   : Bot_Front / Bot_Back / Bot_Left / Bot_Right
                      horizontal bars at y = 0.035 + BOX_Y offset
    4 top ring      : Top_Front / Top_Back / Top_Left / Top_Right

 11. ENEMY MOVEMENT (TDEnemyView)
════════════════════════════════════════════════════════════════════════════════

  State fields:
    m_PathsPosition    : List<Vector3>  (world positions của path)
    m_CurrentPathIndex : int
    m_HasReachedEnd    : bool           ← guard tránh LoseLife nhiều lần [4.5]
    m_HasBeenReturned  : bool           ← guard tránh double ReturnToPool [8.5]
    m_EnemyHealth      : float          ← set từ SpawnBatch (baseHP × hpMult) [Phase 11]
    m_MoveSpeed        : float          ← set từ SpawnBatch (baseSpeed × speedMult) [Phase 11]
    m_EnemyKey         : string         ← unique "w{wave}-{type}-e{i}-{instanceId}"
    EnemyType          : EnemyType      ← property { get; private set; } [Phase 11]

  PathProgress: m_CurrentPathIndex / m_PathsPosition.Count (0→1)
    → Tower dùng để ưu tiên enemy gần GateEnd nhất

  State fields (session 16):
    m_IsDying       : bool  ← guard TakeDamage + Update khi đang play Die anim [Phase 13]
    m_DieDuration   : float ← nhận từ EnemyData.dieDuration qua Initialize() [Phase 13]

  Animation fields [Phase 13]:
    m_Animator       : Animator — GetComponent<Animator>() trong Awake()
    TRIGGER_WALK     : const "Walk"
    TRIGGER_GET_HIT  : const "GetHit"
    TRIGGER_DIE      : const "Die"
    TriggerSafe(str) : null-safe SetTrigger (bỏ qua nếu m_Animator == null)

  Initialize(key, hp, speed, dieDuration, enemyType): reset state, set stats,
    Rebind()+Update(0) để reset animator từ pool → TriggerSafe(WALK)
    Subscribe + Register [Phase 11, 13]
  TakeDamage(dmg): guard m_IsDying; health -= dmg; ≤ 0 → Die(); else TriggerSafe(GET_HIT)
  Die(): m_IsDying=true; Unsubscribe+Unregister; TriggerSafe(DIE);
         dieDuration>0 → Coroutine → PoolReturn(); else PoolReturn()
  PoolReturn(): guard → m_HasBeenReturned=true → Pool.Release
  ReturnToPool(): reach-end path → guard → Unsubscribe+Unregister → Pool.Release [8.5]
  OnDestroy():    chỉ cleanup nếu !m_HasBeenReturned (scene unload safety)

  Update():
    guard: m_PathsPosition==null || Count==0 || m_HasReachedEnd || m_IsDying → return
    if m_CurrentPathIndex < Count:
      MoveTowards(target, speed*dt)
      LookRotation(dir)
      if dist < 0.1f: m_CurrentPathIndex++
    else:
      m_HasReachedEnd = true
      TDPlayerLifeControl.api.LoseLife()
      TDGameStateControl.api?.OnEnemyRemoved()  ← [Phase 8: escape cũng là removed → Victory check]
      ReturnToPool()   ← [Phase 8.5: không Destroy — pool release]

  Difficulty Ratio Table (phân phối % + multiplier stats):

    Difficulty | Normal% | Fast% | Tank% | Boss% | HP mult | Speed mult
    -----------|---------|-------|-------|-------|---------|------------
    Easy       |   80%   |  15%  |   4%  |   1%  |  ×0.8   |   ×0.9
    Normal     |   60%   |  25%  |  12%  |   3%  |  ×1.0   |   ×1.0
    Hard       |   45%   |  30%  |  18%  |   7%  |  ×1.2   |   ×1.1
    Extreme    |   30%   |  30%  |  25%  |  15%  |  ×1.5   |   ×1.2
    Nightmare  |   15%   |  25%  |  35%  |  25%  |  ×2.0   |   ×1.5

  Ví dụ: difficulty=Hard, totalEnemies=50
    Normal = 45% × 50 = 22.5 → 23 con
    Fast   = 30% × 50 = 15   → 15 con
    Tank   = 18% × 50 =  9   →  9 con
    Boss   =  7% × 50 =  3.5 →  3 con
    (làm tròn, đảm bảo sum = totalEnemies)

  HP/Speed multiplier apply lúc runtime khi spawn:
    float hp    = baseData.baseHP    * difficultyConfig.hpMult;
    float speed = baseData.baseSpeed * difficultyConfig.speedMult;

  ── 2-Path System ─────────────────────────────────────────────────────────────

  Mỗi màn có 2 đường → enemy split theo path1Ratio:
    path1Count = Round(totalEnemies × path1Ratio)
    path2Count = totalEnemies - path1Count

    path1: tỉ lệ type tương đương, Boss ưu tiên path nhiều hơn (path1 nếu path1Ratio ≥ 0.5)

  Spawn: mỗi path có spawn queue riêng, spawn đan xen (hoặc đồng thời)

  ── Wave Subdivision Auto ─────────────────────────────────────────────────────

  totalEnemies chia đều cho waveCount:
    basePerWave = totalEnemies / waveCount
    remainder   = totalEnemies % waveCount (distributed to first N waves)

  Mỗi wave: spawn basePerWave (hoặc +1) enemy, cách nhau spawnInterval giây
  Giữa các wave: waveInterval giây (qua PauseAwareDelay)

  ── Spawn Logic Flow (Phase 11) ───────────────────────────────────────────────

  1. LevelConfig loaded từ SO → GetLevel(levelIndex)
  2. Auto-distribute: DifficultyRatioTable → counts per type (Normal/Fast/Tank/Boss)
  3. Split thành 2 spawn queues (path1 / path2) theo path1Ratio
  4. Chia đều theo waveCount → spawnQueuePerWave[][]
  5. For each wave:
       onWaveStart → GateView.PlaySpawnEffect()
       For each enemy in wave:
         Xác định EnemyType từ queue → lấy EnemyData → tính HP×mult, speed×mult
         GetOrSpawn prefab tương ứng từ pool
         enemy.Initialize(key, hp, speed)
         await PauseAwareDelay(spawnInterval)
       await PauseAwareDelay(waveInterval)

    O(1)      — constant: HashSet.Contains, array index
    O(log n)  — logarithmic: MinHeap push/pop, Binary Search
    O(n)      — linear: List scan, Array traverse
    O(n log n)— List.OrderBy, merge sort, heap sort trên toàn mảng
    O(n²)     — nested loop, Bubble Sort

  MinHeap Binary Heap:
    Cây nhị phân trong mảng: parent(i)=(i-1)/2, left=2i+1, right=2i+2
    Parent luôn ≤ Children (Min property)
    Push: add cuối → BubbleUp (swap với parent nếu nhỏ hơn) — O(log n)
    Pop:  lấy root → move last→root → SiftDown (swap với con nhỏ hơn) — O(log n)

  Lazy Deletion Pattern:
    Thay vì update/remove ngay (expensive) → re-insert với priority mới
    Khi pop ra bản cũ → closedSet.Contains → skip
    Trade-off: bộ nhớ cao hơn (duplicates trong heap) ↔ tốc độ tốt hơn (no linear scan)
    Unity parallel: Destroy() cuối frame, DOTween.Kill() mark+cleanup, Application.Quit() deferred
